Campus Placement System

📌 Project Overview

Campus Placement System is a web-based application developed to manage college placement activities. It helps manage student details, company information, and placement records in one place.

🎯 Objectives

- Manage student information.
- Store company details.
- Maintain placement records.
- Track placement status.
- View placement statistics through a dashboard.

✨ Features

- Student Management (Add, View, Edit, Delete)
- Company Management (Add, View, Edit, Delete)
- Placement Management (Add, View, Edit, Delete)
- Dashboard with summary counts
- Search and filter functionality
- Form validation
- MySQL database integration

🛠️ Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Thymeleaf
- HTML
- CSS
- Bootstrap
- MySQL
- Maven
- IntelliJ IDEA
- Git & GitHub

📂 Project Modules

1. Student Module: Manages student details.
2. Company Module: Manages company information and job roles.
3. Placement Module: Maintains student placement records.
4. Dashboard Module: Displays overall placement statistics.

⚙️ Installation and Setup

1. Clone the repository:

   git clone https://github.com/ParulVerma12345/Campus-Placement-System.git

2. Open the project in IntelliJ IDEA.

3. Create a MySQL database:

   CREATE DATABASE placement_System;

4. Configure your MySQL username and password in "application.properties".

5. Reload Maven dependencies.

6. Run "CampusPlacementSystemApplication.java".

7. Open the application in your browser:

   "http://localhost:8080/"
